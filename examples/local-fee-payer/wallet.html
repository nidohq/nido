The boundary has moved.

The calling app cannot read this origin’s encrypted vault or use a passkey scoped to wallet.localhost. The wallet’s own code remains trusted: it decrypts the phrase only after the WASI check allows this exact envelope. The guest cannot sign. WASI isolates the checker; it does not protect it from a compromised wallet host. A phrase backup, wallet compromise or privileged browser extension can bypass this policy. HD paths do not provide independent compromise protection.

Local fixtures only. A passkey prompt approves C and unlocks this trusted wallet; it is not a separate cryptographic signature over the final fee envelope. The wallet enforces that fee decision.
